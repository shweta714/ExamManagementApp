# Exam Management App (Vite + React)

Simple in-memory exam management single-page app built with Vite + React.

## Quick start (Windows PowerShell)

```powershell
cd "D:/exam management/ExamMnagementApp"
npm install
npm run dev
```

Open the URL shown by Vite (usually `http://localhost:5173`).

Features included:
- List of exams
- Add new exam
- View exam details
- Delete exams

If you want a backend or persistence, tell me which stack you'd like (Node/Express, Firebase, etc.).
